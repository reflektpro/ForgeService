# ForgeService

**ForgeService** — профессиональная, масштабируемая система управления автосервисом премиум-уровня.

Локальный сервер + мощное Android-приложение для приёмщиков, мастеров и руководителя небольшого/среднего автосервиса (СТО, детейлинг, мобильный сервис, специализированный сервис).

---

## 🎯 Назначение и целевая аудитория

Приложение создано для **реального использования** в небольших и средних автосервисах (3–12 человек персонала).

**Кому реально нужно:**
- Владелец / руководитель СТО (аналитика, контроль, отчёты)
- Приёмщик автомобилей
- Мастера (диагностика, фотофиксация, учёт работ и запчастей)
- Бухгалтер / администратор (склад, платежи, документы)

Вместо кучи Excel-таблиц, блокнотов, WhatsApp и потерянных фотографий — единая профессиональная система.

---

## 🔥 Почему проект получился большим и пафосным

- **Богатая доменная модель** (12+ сущностей со связями и историей)
- **Центральная сущность — Заказ-наряд** (Work Order) с полноценным жизненным циклом
- **Профессиональная фотофиксация** с возможностью аннотирования фотографий (стрелки, выделения, комментарии)
- **Реал-тайм синхронизация** между всеми сотрудниками (WebSocket)
- **Визуальное управление боксами** и загрузкой
- **Полноценный склад** с приходом/расходом и контролем остатков
- **Таймлайн истории обслуживания** автомобиля (один из самых сильных экранов)
- **Генерация официальных документов** (Акт приёмки-передачи, Заказ-наряд, Счёт, Акт выполненных работ) в PDF
- **Мощная аналитика** и дашборд руководителя
- **Оффлайн-режим + синхронизация** (мастер может работать на выезде)
- **Многоуровневые роли** (Администратор, Приёмщик, Мастер, Руководитель)
- Полноценный REST API + WebSocket + файловая система для фото

Это не "студенческая поделка". Это реальный инструмент, которым можно пользоваться.

```
┌─────────────────────┐          ┌──────────────────────────┐
│   Android App       │  Wi-Fi   │   Local ForgeService     │
│   (мастера +        │◄────────►│   Server (FastAPI)       │
│    приёмщики)       │          │                          │
└─────────────────────┘          │  • REST API              │
                                 │  • WebSocket (real-time) │
                                 │  • SQLite (основная БД)  │
                                 │  • Хранение фотографий   │
                                 │  • Генерация PDF         │
                                 └──────────┬───────────────┘
                                            │
                                 ┌──────────▼───────────────┐
                                 │   Web Dashboard (опц.)   │
```

- **Сервер** — всегда запущен на компьютере в офисе/кладовке.

- Реал-тайм обновления: добавил фото — у всех, кто открыт этот заказ-наряд, сразу появилась.
- Полная работа возможна и при временной потере связи (оффлайн + очередь синхронизации).

## 📊 Доменная модель (основные сущности)

| Сущность              | Описание                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| `Client`              | Владелец(и) автомобиля. Контакты, история, заметки                        |
| `Vehicle`             | Автомобиль. Полная техническая карта + текущий пробег + фото             |
| `VehicleHistory`      | Запись изменения пробега / собственника                                  |
| `Employee`            | Сотрудник (роли: admin, receptionist, mechanic, manager)                 |
| `WorkOrder`           | **Главный документ** — Заказ-наряд                                       |
| `WorkOrderItem`       | Работа в заказ-наряде (название, нормочасы, цена, исполнитель)           |
| `Part`                | Запчасть на складе                                                       |
| `WorkOrderPart`       | Использованная запчасть в конкретном ЗН (списание)                       |
| `Photo`               | Фотография с категорией и аннотациями (привязана к ЗН или конкретной работе) |
| `PhotoAnnotation`     | Аннотации на фото (координаты, тип, текст)                               |
| `Appointment`         | Запись на сервис / предварительная запись                                |
| `Payment`             | Платежи по заказ-наряду                                                  |
| `InventoryTransaction`| Движение товара на складе (приход / расход / инвентаризация)             |
| `ServiceTemplate`     | Шаблон типовой услуги (для быстрого создания работ в ЗН)                 |
| `Bay`                 | Сервисный бокс (визуальное планирование)                                 |

Статусы Заказ-наряда (жёсткий workflow):
`new` → `diagnostics` → `awaiting_approval` → `in_progress` → `awaiting_parts` → `quality_control` → `ready` → `completed` / `cancelled`

## 📱 Основные экраны Android-приложения (премиум)

1. **Дашборд руководителя**  
   KPI: активные ЗН, выручка за период, загрузка боксов (%), средний чек, топ-5 услуг, предупреждения (закончились запчасти, просроченные ЗН).

2. **Автомобили**  
   Мощный список + фильтры + поиск по VIN/гос.номеру/марке. Быстрый переход в карточку.

3. **Карточка Автомобиля + История**  
   Полная тех. информация. **Вертикальный красивый таймлайн** всех предыдущих ремонтов (самый сильный экран для демонстрации).

4. **Клиенты**  
   Список + карточка клиента со всеми его автомобилями.

5. **Заказ-наряды**  
   Kanban-подобный или фильтруемый список. Цветовая индикация статуса. Поиск.

6. **Экран Заказ-наряда** (самый жирный и сложный)  
   - Шапка (авто + клиент + текущий статус + бокс)
   - Блок приёмки (показания, комплектность)
   - Список работ + добавление из шаблонов
   - Список использованных запчастей + списание
   - **Галерея фото по категориям** (Приёмка / Дефекты / В процессе / Результат)
   - Возможность **аннотировать фото** (рисовать стрелки, круги, добавлять текст)
   - Блок рекомендаций мастеров + отметки "одобрено клиентом"
   - Назначенные мастера + часы
   - Финансовый блок (итого работы / запчасти / к оплате)
   - История изменений и комментариев
   - Кнопки перехода по статусам + подпись клиента

7. **Создание / Редактирование Заказ-наряда** (мастер-форма)

8. **Склад запчастей**  
   Список, поиск, фильтр "заканчивается". Карточка детали + история движения. Приход товара.

9. **Боксы и загрузка**  
   Визуальная схема боксов (карточки или простой план). Перетаскивание ЗН между боксами (или выбор). Показ текущей загрузки.

10. **Календарь и запись**  
    Просмотр и создание предварительных записей. Проверка свободных слотов.

11. **Аналитика и отчёты**  
    Графики (выручка по дням/неделям, популярность услуг, эффективность мастеров). Экспорт отчёта за период в PDF.

12. **Справочники** (Услуги, Шаблоны работ, Мастера, Боксы, Настройки компании)

13. **Профиль и синхронизация**

## ⚡ Ключевые "вау" фичи для защиты

- Реал-тайм: открыли один и тот же заказ-наряд на двух телефонах — один добавил работу/фото/изменил статус → у второго мгновенно обновилось.
- Аннотирование фотографий прямо в приложении (очень профессионально выглядит).
- Полноценная история автомобиля — можно показать "вот этот клиент уже третий раз приезжает, вот что мы ему делали".
- Генерация красивых PDF-документов на сервере.
- Оффлайн-режим: мастер может полностью заполнить заказ-наряд без связи, потом синхронизировать.
- Визуальное управление боксами.

## ▶️ Как запустить прямо сейчас (Windows)

### Сервер (уже полностью рабочий)

```powershell
# Из корня проекта
cd ForgeService\server

# Первый раз
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Наполнить реалистичными данными (очень важно для защиты!)
python seed.py

# Запустить сервер
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Или используй готовый скрипт:

**Самый простой способ для Windows (рекомендую):**
- Дважды кликни `scripts/seed.bat` (первый раз)
- Потом дважды кликни `scripts/start-server.bat`

Это обычные .bat файлы — они почти всегда запускаются нормально.

В .bat файлах уже прописан `set PYTHONPATH=.`, чтобы импорты `from app.xxx` работали.

Или вручную в PowerShell (если .bat не хочет):

```powershell
cd E:\pyproject\giga_project\ForgeService\server
.\venv\Scripts\Activate.ps1
$env:PYTHONPATH = "."
python seed.py
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

После запуска:
- Swagger: http://localhost:8000/docs
- Web dashboard (офис): открой `web-dashboard/index.html` в браузере (поменяй fetch на http://твой-ip:8000 если нужно)

### Android

**Какую папку открывать в Android Studio:**

Открывай **только** папку `android-app`, а не всю `ForgeService`!

Пример пути:
`E:\pyproject\giga_project\ForgeService\android-app`

В Android Studio:
- File → Open...
- Выбери именно папку `android-app`
- Дождись Gradle Sync

После открытия:
1. В `ApiClient.kt` укажи правильный адрес сервера:
   - Эмулятор → `http://10.0.2.2:8000`
   - Реальный телефон в одной Wi-Fi сети → `http://192.168.x.x:8000` (IP твоего компьютера)
   - Публичный сервер (Railway и т.д.) → `https://your-app.up.railway.app` (https + без порта)

Если Android Studio пожалуется на отсутствие Gradle wrapper — согласись на автоматическую настройку.

Скелет приложения уже есть (премиум тёмная тема, навигация, несколько красивых экранов-заглушек, WebSocket менеджер, Retrofit клиент).

Дальше мы будем допиливать детальный экран Заказ-наряда, фото + аннотации на Canvas, реал-тайм и т.д.

## ☁️ Публичный сервер (бесплатно)

Чтобы не запускать сервер локально каждый раз (особенно на защите), можно выложить бэкенд на бесплатный хостинг.

**Рекомендуемый вариант: Railway.app** (самый простой + есть persistent volume для SQLite и фото).

Подробная инструкция: смотри файл [server/DEPLOY_RAILWAY.md](server/DEPLOY_RAILWAY.md)

Кратко:
1. Залей проект на GitHub.
2. В Railway создай проект из репозитория (root directory = `server`).
3. Добавь **Volume** (папка `/data`).
4. Задай переменные окружения:
   ```
   DATABASE_URL=sqlite+aiosqlite:////data/forgeservice.db
   PHOTOS_DIR=/data/photos
   ```
5. После деплоя один раз выполни `python seed.py` через Shell в Railway.
6. В `ApiClient.kt` поменяй `baseUrl` на публичный адрес (`https://....up.railway.app`).

После этого приложение будет работать у кого угодно без запуска сервера на ноутбуке.

Альтернативы: Fly.io, Render.com (для Render лучше сразу на Postgres).
