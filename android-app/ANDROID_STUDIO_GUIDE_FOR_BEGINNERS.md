# Полная инструкция для тех, кто вообще не шарит в Android Studio

## Самое важное, что нужно понять сразу

**Ты не запускаешь файл `MainActivity.kt`.**

В Android ты запускаешь **всё приложение целиком**.  
Android Studio запускает не отдельный файл, а **конфигурацию "app"**.

---

## Шаг 1: Убедись, что открыл правильную папку

Ты должен открыть **только** эту папку:

```
ForgeService\android-app
```

**НЕ** открывай всю папку `ForgeService`!

Если ты открыл не ту папку — закрой проект и открой заново:
- File → Close Project
- File → Open...
- Выбери папку `android-app`

---

## Шаг 2: Первый запуск (самый долгий)

После открытия папки Android Studio начнёт делать **Gradle Sync**.

Что ты увидишь:
- Внизу появится строка "Gradle build running..." или "Syncing..."
- Это может идти **5–20 минут** в первый раз (скачивает кучу всего).

**Что делать:**
- Просто подожди.
- Не закрывай Android Studio.
- Если вылезут окна "Install missing platforms / Build Tools" — нажимай **Install** и соглашайся.

Если внизу красным написано что-то про ошибки — пока не пугайся, иногда это проходит после синка.

---

## Шаг 3: Создай эмулятор (если ещё нет)

1. В правом верхнем углу найди иконку телефона с маленькой стрелкой вниз (или зайди в меню **Tools → Device Manager**).
2. Нажми **Create Device**.
3. Выбери любой телефон, например:
   - Pixel 6 или Pixel 8
   - System Image: **Tiramisu** или **UpsideDownCake** (Android 13/14) — желательно с Google Play
4. Нажми **Next → Finish**.

После создания эмулятор появится в списке.

---

## Шаг 4: Как запустить приложение (главное!)

1. В верхней панели найди выпадающий список (обычно там написано **app**).
2. Рядом с ним должна быть **зелёная кнопка Play** (треугольник).
3. Выбери в списке свой эмулятор (который ты создал).
4. Нажми зелёную кнопку **Play**.

Если зелёной кнопки нет или написано "Edit Configurations":

- Нажми на выпадающий список → **Edit Configurations...**
- Нажми **+** (плюс) вверху слева
- Выбери **Android App**
- В поле **Module** выбери **:app**
- Нажми **OK**

Теперь зелёная кнопка должна появиться.

---

## Шаг 5: Что будет происходить

- Эмулятор запустится (может быть медленно первый раз).
- Приложение установится.
- Откроется твой ForgeService.

Что должно быть внутри:
- Нижняя панель навигации (Дашборд, Автомобили, Заказ-наряды и т.д.)
- При открытии "Дашборд" приложение попытается сходить на сервер.

**Если сервер у тебя запущен**, то на дашборде должны появиться реальные цифры.

## Частые проблемы и решения

**"Cannot find AVD" или нет эмуляторов**
→ Открой Device Manager и создай устройство.

**Красные ошибки в коде (MainActivity.kt и т.д.)**
→ Это нормально на первом открытии. Подожди окончания Gradle Sync.

**"Gradle project sync failed"**
→ Попробуй:
- File → Invalidate Caches / Restart → Invalidate and Restart

**Приложение запускается, но пустой экран или краш**
→ Убедись, что твой сервер запущен.
→ В эмуляторе адрес сервера должен быть `http://10.0.2.2:8000`

**Хочу запустить на реальном телефоне**
→ Включи на телефоне "Отладку по USB" + "Установка по USB".
→ Подключи телефон кабелем.
→ В списке устройств вместо эмулятора выберешь свой телефон.

## Полезные советы

- Первый запуск — самый тяжёлый. Потом будет быстрее.
- Если что-то сильно сломалось — сделай **File → Invalidate Caches / Restart**.
